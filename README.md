# React Vite Boilerplate Documentation

This repository contains the documentation for the React Vite Boilerplate project.

## Overview

The boilerplate is designed for enterprise-scale React applications with:

- React + TypeScript
- Vite
- Feature-based architecture
- Atomic Design UI structure
- Centralized API layer
- Form validation using Zod
- React Router
- ESLint Flat Config
- Scalable module boundaries

## Documentation Goals

- Standardize project structure
- Define development conventions
- Provide onboarding guidance
- Document architecture decisions
- Improve maintainability and scalability

Documentation is currently being expanded and refined.
